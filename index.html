Module 07 · Deterministic analytical engine

Project finance lab

Build a simplified project-finance case from construction funding through operating cash generation and debt repayment. Change assumptions to see whether project cash flows can support the financing structure.

Illustrative assumptions only

1 · Project and operating assumptions

2 · Sources of construction financing

Funding mix: IFC loan 30% · other debt 35% · sponsor equity 35%.

All monetary values use the same user-selected currency unit (millions). IFC and other debt are modelled as separate level-payment amortising loans, with no grace period or fees. Sponsor equity is the residual funding source. Assumptions are synthetic, not project facts or market benchmarks.

Project cash flows · annual timeline

Construction funding in Year 0; operating revenues, costs and each lender's debt service in subsequent years.

Live scenario

The chart will update automatically when you change an assumption.

Year 0 separates initial CAPEX from IFC debt, other debt and sponsor equity. Operating-year bars show revenues and cash outflows by category. All bars use the same scale.
The model recalculates as assumptions change.

How to read the viability screen

  • Project NPV: initial CAPEX plus the present value of unlevered CFADS, discounted at WACC.
  • DSCR: CFADS divided by combined IFC and other senior debt service in each year.
  • LLCR: present value of CFADS over the longest debt tenor divided by opening senior debt.
  • Preliminary screen: positive project NPV and minimum DSCR at or above the entered covenant. It is an initial test, not a bankability conclusion.

Model limitations

  • Simplified EBITDA-based cash-tax proxy; no depreciation or interest tax shields.
  • No construction phasing, ramp-up, working capital, reserves, fees, grace periods or balloon payments.
  • Annual level-payment amortisation; no debt sculpting, refinancing, FX mismatch or lifecycle overhaul CAPEX.
  • Does not model dividends, distributions, sponsor support or a full equity IRR.

Screening model only. The IFC loan is a hypothetical financing tranche, not a representation of IFC appetite, commitment or product terms. No project-specific facts are preloaded.

Agent catalogue

What each specialist agent analyses and what it hands back to the investment officer.

01 · Investor Intelligence Agent

Analyses: mandates, ownership, strategy, portfolio, international track record, instruments, ticket sizes and disclosed constraints.

Output: investor profile, comparable transactions, capability map, evidence gaps and tailored research questions.

02 · Opportunity Origination Agent

Analyses: national infrastructure plans, PPP/concession programmes, public pipelines, procurement notices, sponsors and project maturity.

Output: sourced opportunity longlist, project fact sheets, maturity classification and origination hypotheses.

03 · Investment Matching Agent

Analyses: investor mandate against project sector, geography, size, financing structure, risk allocation and development objectives.

Output: dimension-by-dimension fit matrix, mismatch flags, missing evidence and potential IFC additionality to test.

04 · Project Assessment Agent

Analyses: concession design, revenue model, demand evidence, CAPEX/OPEX obligations, regulatory, execution, E&S and integrity risks.

Output: preliminary project assessment, risk register, diligence checklist and investment questions.

05 · Pipeline Monitoring Agent

Analyses: changes to tender status, auction dates, project documents, sponsors, bidders and source freshness.

Output: change alerts, updated pipeline records, source diffs and recommended follow-up actions.

06 · Investor Engagement Agent

Analyses: investor relationship history, prior interactions, relevant opportunities, meeting notes and pending commitments.

Output: account brief, meeting agenda, stakeholder map, action log and follow-up draft. It never invents contacts or meetings.

07 · Project Finance Agent

Analyses: cash-flow inputs, sources and uses, debt sizing, repayment profile, DSCR/LLCR and scenario sensitivities using deterministic calculations.

Output: financing case, covenant table, sensitivity results and explicit model limitations — only where input data exist.

08 · Evidence & Document Agent

Analyses: contracts, tender notices, annual reports, regulatory decisions and financial disclosures; extracts claims, tables and document versions.

Output: searchable evidence register, source-linked claim cards, extracted data and unresolved contradictions.

09 · Country Intelligence Agent

Analyses: macroeconomic conditions, FX and convertibility, sovereign/sub-sovereign context, regulatory institutions, PPP frameworks and development finance activity.

Output: country risk brief, macro dashboard, sector context and country-level diligence questions.

10 · Orchestrator / Investment Brief Agent

Analyses: the task, required specialist workflows, cross-agent findings, source quality, contradictions and missing inputs.

Output: prioritised workplan and integrated origination note: investor, project, fit, IFC role, risks, evidence gaps and next actions.

How agents work together

Example: the Opportunity Origination Agent discovers a Brazilian toll-road concession; the Evidence Agent retrieves its notice and contract; the Country Agent adds Brazil context; the Project Assessment and Finance Agents examine risks and financing inputs; the Investor Intelligence Agent profiles CDP; the Matching Agent compares capabilities and project needs; the Engagement Agent prepares a discussion plan; the Orchestrator consolidates the investment brief.

Conceptual agent design These are proposed specialised workflows, not ten live autonomous LLM agents in the current static website. The demo contains selected interactive workflows and deterministic calculations; live model inference, scheduled monitoring and persistent agent memory require a backend.

What AI does

  • Extracts and summarises relevant information.
  • Classifies investors, sectors, geographies and projects.
  • Highlights inconsistencies, missing information and diligence questions.
  • Drafts investor briefs and meeting notes.

What AI must not do

  • Invent traffic, CAPEX, IRR, DSCR or debt terms.
  • Make credit, integrity, E&S or investment decisions.
  • Present assumptions as facts or infer investor appetite.
  • Replace due diligence or professional judgement.
